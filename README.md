# Data_Analytics
Overview
This repository contains Exploratory Data Analysis (EDA) projects for five different datasets:

Titanic Survival Dataset

Netflix Movies and TV Shows

NYC Airbnb Listings

Sleep Health and Lifestyle

Financial Transactions

Each project provides insights into the respective dataset through data cleaning, visualization, and statistical analysis.

Projects
1. Titanic Survival Analysis
File: titanic_analysis.ipynb or titanic_analysis.py
Dataset: Passenger information from the Titanic disaster (1912)
Key Analyses:

Survival rates by passenger class, gender, and age

Family size impact on survival

Fare distribution across classes

Missing value treatment

Correlation between variables

2. Netflix Content Analysis
File: netflix_analysis.ipynb or netflix_analysis.py
Dataset: Netflix movies and TV shows (as of recent snapshot)
Key Analyses:

Content distribution by type, country, and release year

Rating analysis

Duration trends over time

Word cloud analysis of descriptions

Content addition patterns over time

3. NYC Airbnb Market Analysis
File: nyc_airbnb_analysis.ipynb or nyc_airbnb_analysis.py
Dataset: Airbnb listings in New York City
Key Analyses:

Price distribution by neighborhood

Room type popularity

Availability patterns

Price correlations with location and amenities

Seasonality effects on pricing

4. Sleep Health and Lifestyle Analysis
File: sleep_health_analysis.ipynb or sleep_health_analysis.py
Dataset: Sleep patterns and lifestyle factors
Key Analyses:

Sleep duration vs. quality relationships

Occupation impact on sleep

Physical activity correlations

Stress level analysis

BMI and sleep connections

5. Financial Transactions Analysis
File: financial_transactions_analysis.ipynb or financial_transactions_analysis.py
Dataset: Sample financial transaction records
Key Analyses:

Transaction amount distributions

Fraud detection patterns

Time-based transaction trends

Merchant category analysis

Geographic spending patterns
